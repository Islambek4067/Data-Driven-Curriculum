# Data-Driven Curriculum

Платформа для методистов: анализирует результаты тестов по темам, находит причины
слабых разделов, честно сравнивает учебники и подсказывает, как распределить часы.

## Запуск

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python -m pip install -r requirements.txt
```

```bash
.venv/Scripts/streamlit run app.py
```

Демо-данные создаются сами при первом запуске. Проверка модели в консоли:
`.venv/Scripts/python validate.py`.

## Язык интерфейса

Приложение открывается на казахском. Переключатель «Қазақша / Русский» в правом верхнем углу
меняет весь интерфейс, названия тем и язык подсказок для ИИ. Тексты лежат в `core/i18n.py`:
у каждой строки есть казахская и русская версия.

## Сценарий демо, 3 минуты

1. **Темы.** Три разные причины слабых результатов: трудная тема, провал в базе, брак вопросов.
2. **Учебники.** Лидер по средним баллам: А. Включить «Учесть уровень школ»: лидером становится Б.
3. **Часы.** Оптимальный план при той же сумме часов, затем свой перенос.
4. **Решение для методсовета.** Готовый документ на русском и казахском.
5. **Проверка модели.** Выводы сравниваются с правдой, заложенной в данные.

## Реальные данные: TIMSS 2023, Казахстан

Переключатель «Набор данных» в шапке открывает настоящие ответы казахстанских восьмиклассников
по математике из TIMSS 2023: 187 школ, 6 359 учеников, 200 вопросов, 8 тем.

- Работают «Темы» (диагноз и брак вопросов), сравнение «город и село, язык обучения» и ИИ-чат.
- Учебников и часов по темам в TIMSS нет, поэтому этих вкладок в этом режиме нет.
- Поправка «при равных условиях» здесь — домашние образовательные ресурсы ученика (входного теста в TIMSS нет).
- Считается доля верных ответов без выборочных весов и правдоподобных значений IEA, это не официальная статистика TIMSS.
- Связи между темами («Дроби» → «Пропорции» и т. д.) задали мы по логике программы, это не данные TIMSS.

Как получить данные заново (архив 949 МБ с [timss2023.org/data](https://timss2023.org/data)):

```
python tools/import_timss.py data/timss_raw/T23_Data_SPSS_G8.zip data/timss_raw/T23_ItemInformation_G8.xlsx
```

Источник: TIMSS 2023 International Database, IEA. Только некоммерческое учебное и исследовательское использование.

## ИИ-помощник

Вкладка «Спросить ИИ»: методист задаёт вопрос по-русски или по-казахски, модель отвечает только по
посчитанным результатам. Программа сверяет каждое число в ответе с расчётами и помечает выдуманные.
Сводку, которую видит модель, можно открыть под чатом.

Ключ кладётся в `.streamlit/secrets.toml` (файл в `.gitignore`):

```
XKIRO_API_KEY = "ключ"
```

Вместо xKiro можно указать `ANTHROPIC_API_KEY`. Модель выбирается во вкладке. У xKiro модели Claude
платные (нужен тариф или пополненный баланс), Mistral Large бесплатная. Без ключа или интернета
вкладка показывает подсказку, остальная платформа работает.

## Свои данные

Кнопка «Загрузить данные» принимает zip с CSV-файлами:

| Файл | Колонки |
|---|---|
| `topics.csv` | `topic_id, name_ru, name_kz, planned_hours, prereqs` (базовые темы через `;`) |
| `schools.csv` | `school_id, school_type, language, textbook` |
| `students.csv` | `student_id, school_id, pretest` |
| `items.csv` | `item_id, topic_id` |
| `responses.csv` | `student_id, item_id, correct` (0 или 1) |
| `hours.csv` | `school_id, topic_id, hours` |
| `coverage.csv` (необязательно) | `textbook, topic_id, exercises, examples` |

## Что реально, а что пока нет

- Вся статистика считается по-настоящему.
- Данные синтетические, настоящих результатов школ в проекте нет.
- `coverage.csv` в демо задан вручную. Извлечение упражнений из PDF учебников с помощью ИИ не реализовано.
- Выводы об учебниках и часах опираются на наблюдательные данные и не заменяют пилот.

## Как устроено

- `core/data.py`: загрузка и проверка файлов.
- `core/analysis.py`: брак вопросов, диагноз тем, модель со случайным эффектом школы, оптимизация часов.
- `core/report.py`: документ для методсовета.
- `core/charts.py`: графики.
- `generate_data.py`: синтетика с заложенной правдой.
- `validate.py`: сверка выводов с заложенной правдой.
